# pull_buf_proto.dart — Hướng dẫn sử dụng

> Script: `scripts/pull_buf_proto.dart`
> Config: `scripts/buf_modules.json`
> Make targets: `make/codegen.mk` (`proto_buf`, `proto_buf_list`, `proto_buf_refs`)
> Ghi chú ngày: 2026-09-28

## 1. Script này làm gì?

Kéo `.proto` **trực tiếp từ Buf Schema Registry (BSR)** rồi generate code Dart + gRPC.

- **Không cần** file `.proto` ở local, **không cần** `protoc` / `protoc_plugin`.
- Chỉ cần **`buf` CLI** (máy này: `C:\Tools\buf.exe`, v1.63.0) + `dart`.
- Codegen chạy bằng remote plugin `buf.build/protocolbuffers/dart:v25.0.0` (cùng version với `buf.gen.yaml` ở root repo).
- Mỗi lần generate sẽ ghi file `.buf-commit` vào thư mục output để biết code hiện tại được build từ commit BSR nào.

## 3. Các lệnh hay dùng

Chạy từ root repo (`D:\nexsoft\tbchat_CS_Fav`):

```bash
# Xem các module đã cấu hình (không gọi mạng)
dart scripts/pull_buf_proto.dart --list

# Xem refs (branch/tag) của từng module trên BSR
dart scripts/pull_buf_proto.dart --refs              # tất cả module
dart scripts/pull_buf_proto.dart storage --refs      # 1 module

# Chỉ in commit mới nhất sẽ được dùng, KHÔNG generate
dart scripts/pull_buf_proto.dart --all --print-commit
dart scripts/pull_buf_proto.dart storage --print-commit

# Generate
dart scripts/pull_buf_proto.dart --all                    # mọi module
dart scripts/pull_buf_proto.dart storage                  # 1 module
dart scripts/pull_buf_proto.dart storage subscription     # nhiều module

# Generate theo ref khác (chỉ override lần chạy này, không sửa config)
dart scripts/pull_buf_proto.dart storage --ref qa

# Generate từ 1 commit cố định (chỉ áp dụng cho 1 module)
dart scripts/pull_buf_proto.dart storage --commit a403a31583fc417f8c0b4476bc3dc150

# Ép generate lại dù đã up to date
dart scripts/pull_buf_proto.dart storage --force

# Module ad-hoc không có trong config (bắt buộc --out)
dart scripts/pull_buf_proto.dart buf.build/nexsoft/foo:dev --out lib/features/x/gen
```

### Bảng option

| Option | Ý nghĩa |
|---|---|
| `--all`, `-a` | Generate mọi module trong config |
| `--list`, `-l` | In các module đã cấu hình rồi thoát |
| `--refs` | In refs của module trên BSR rồi thoát (không truyền tên → tất cả module) |
| `--ref <branch\|tag>` | Override ref (mặc định: ref trong config, không có thì `dev`) |
| `--out <dir>` | Thư mục output, tương đối so với root repo |
| `--commit <id>` | Generate từ commit cụ thể — **chỉ 1 module** |
| `--print-commit` | In commit đã resolve rồi thoát |
| `--force`, `-f` | Generate lại dù không có thay đổi **hoặc** thư mục output có file lạ |
| `--help`, `-h` | Hiện usage (chạy không tham số cũng hiện usage) |

Option nhận giá trị viết được cả 2 kiểu: `--ref qa` hoặc `--ref=qa`.

### Qua make (nếu đã cài make)

Máy này **chưa có `make`** (có thể cài bằng `scripts/install_make_windows.bat`). Khi có make:

```bash
make proto_buf                              # = --all
make proto_buf M=subscription               # 1 module
make proto_buf M=storage REF=qa             # override ref
make proto_buf M=subscription ARGS=--force  # truyền thêm option
make proto_buf_list                         # = --list
make proto_buf_refs [M=storage]             # = --refs
```

## 4. Luồng xử lý khi generate

1. Resolve `ref` → commit mới nhất (`buf registry module commit list <module>:<ref> --page-size 1`). Nếu truyền `--commit` thì dùng luôn commit đó.
2. Đọc `<out>/.buf-commit`. Nếu commit **trùng** → in `✅ Already up to date` và bỏ qua (trừ khi `--force`).
3. Kiểm tra thư mục output: nếu có file **không phải `.dart`** và không phải `.buf-commit` → **từ chối chạy** (trừ khi `--force`).
4. Tạo `buf.gen.yaml` tạm (`clean: true`, plugin Dart, `opt: grpc` nếu `grpc: true`) rồi chạy `buf generate <module>:<commit>`.
5. Ghi lại `.buf-commit`:
   ```
   # Generated by scripts/pull_buf_proto.dart — do not edit.
   module: buf.build/nexsoft/storage
   ref: dev                  # hoặc "(pinned commit)" nếu dùng --commit
   commit: <id>
   generated_at: <UTC ISO time>
   ```

## 5. Lưu ý quan trọng

- **`clean: true` xoá sạch thư mục output trước khi generate.**
  - Mỗi module phải có **thư mục output riêng**, dùng chung sẽ xoá code của nhau.
  - **Không để file viết tay** (mapper, extension, ...) trong thư mục generated. Script chỉ bảo vệ file không phải `.dart`; **file `.dart` viết tay vẫn bị xoá mà không cảnh báo**.
  - `--force` bỏ qua cả check file lạ → cẩn thận khi dùng.
- **`--all --ref qa`** áp `qa` cho **mọi** module → `subscription` không có `qa` nên sẽ fail. Nên chạy từng module khi đổi ref.
- **`--ref` không lưu vào config.** Lần chạy tiếp theo không có `--ref` sẽ quay về ref trong `buf_modules.json` (và vì commit khác nên sẽ generate lại).
- Không chắc module có ref nào → chạy `--refs` trước khi truyền `--ref`.
- Nếu lỗi quyền truy cập (unauthenticated / permission denied) khi gọi BSR → đăng nhập: `buf registry login`.
- `--commit` chỉ dùng được với **1 module**, dùng cùng `--all` hoặc nhiều tên sẽ báo lỗi.

## 6. Tình huống thực tế

**Backend vừa cập nhật proto trên `dev`:**
```bash
dart scripts/pull_buf_proto.dart storage --print-commit   # xem commit mới
dart scripts/pull_buf_proto.dart storage                  # generate
git diff --stat lib/features/cloud_storage/data/_grpc/proto_generated
```
Sau đó chạy `/analyze-cloud` để bắt lỗi compile ở mapper/repository.

**Test build QA:**
```bash
dart scripts/pull_buf_proto.dart storage --refs      # kiểm tra có qa / QA
dart scripts/pull_buf_proto.dart storage --ref qa
```

**Quay về commit cũ (rollback / tái hiện bug):**
Lấy commit từ `.buf-commit` trong git history rồi:
```bash
dart scripts/pull_buf_proto.dart storage --commit <commit_id>
```

**Generate lần đầu module `subscription`:**
```bash
dart scripts/pull_buf_proto.dart subscription
```

**Thêm module mới:** thêm 1 entry vào `scripts/buf_modules.json`:
```json
{
  "name": "foo",
  "module": "buf.build/nexsoft/foo",
  "ref": "dev",
  "out": "lib/features/cloud_storage/data/_grpc/foo_generated"
}
```
Field tuỳ chọn: `plugin` (mặc định `buf.build/protocolbuffers/dart:v25.0.0`), `grpc` (mặc định `true`, đặt `false` để bỏ gRPC stubs). Nhớ dùng **thư mục `out` riêng**.
